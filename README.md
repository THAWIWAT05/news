# NEXUS STOCK INTELLIGENCE

เว็บไซต์ติดตามหุ้นและข่าว พร้อมคำนวณตัวชี้วัดทางเทคนิค โดยไม่ต้องใช้หรือซื้อ AI API

## ความสามารถหลัก
- รายการติดตามเริ่มต้น: NVDA, TSLA, AVGO, EOSE, JEPQ และ VOO
- แสดงราคาเปลี่ยนแปลงรายวัน ปริมาณซื้อขาย และกราฟย้อนหลัง
- คำนวณ RSI(14), EMA20/50, SMA20/50/200 และ MACD
- แสดงจุดสูงสุด/ต่ำสุดย้อนหลัง 20 วันเป็นระดับอ้างอิง
- ดึงข่าวแยกตามหุ้นจาก Google News RSS พร้อมลิงก์ข่าวต้นฉบับ
- สรุปพาดหัวเป็นประเด็นเชิงบวก/ลบ/ยังไม่ชัดเจนด้วยการคัดคำ (ไม่ใช่ AI)
- แสดงข้อความผิดพลาดรายหุ้นเมื่อผู้ให้บริการข้อมูลไม่ตอบกลับ
- แก้ไขรายการติดตามและบันทึกไว้ในเครื่อง
- ส่งรายงานหุ้นทั้งหมดเข้า Telegram อัตโนมัติทุก 5 นาที พร้อมแจ้งข่าวสำคัญที่พบใหม่ (เมื่อเซิร์ฟเวอร์ทำงาน)
- ส่งรายงานหุ้นทั้งหมดเข้า Telegram ได้ทันทีจากหน้าเว็บไซต์
- แสดงราคาก่อนเปิดตลาดและหลังปิดตลาดเมื่อ Yahoo Finance มีข้อมูล
- หน้าจอและคำอธิบายหลักเป็นภาษาไทย

## ความต้องการของระบบ
- Node.js รุ่น 18 ขึ้นไป (แนะนำรุ่น LTS)
- อินเทอร์เน็ตสำหรับเรียกข้อมูลราคาและข่าว

## ติดตั้งและเปิดใช้งานใน VS Code
1. ดาวน์โหลดและติดตั้ง Node.js LTS จาก https://nodejs.org/
2. ปิดแล้วเปิด VS Code ใหม่หลังติดตั้ง Node.js
3. แตกไฟล์ ZIP และเปิดโฟลเดอร์ `nexus-stock-intelligence` ใน VS Code
4. เปิดเมนู Terminal → New Terminal
5. ตรวจสอบว่า Node.js พร้อมใช้งาน:
   ```bash
   node -v
   npm -v
   ```
6. ติดตั้งแพ็กเกจ:
   ```bash
   npm install
   ```
7. เปลี่ยนชื่อไฟล์ `.env.example` เป็น `.env` (ไม่ต้องใส่นามสกุล .txt)
8. เริ่มเว็บไซต์:
   ```bash
   npm start
   ```
9. เปิดเบราว์เซอร์ไปที่ http://localhost:3000

หากแก้ไขไฟล์ `.env` ระหว่างที่เซิร์ฟเวอร์ทำงาน ให้หยุดเซิร์ฟเวอร์ด้วย `Ctrl + C` แล้วสั่ง `npm start` ใหม่

## ตั้งค่า Telegram (ไม่บังคับ)
1. เปิด Telegram แล้วค้นหา `@BotFather` เพื่อสร้างบอตและรับ Bot Token
2. เปิดแชตกับบอตที่สร้าง แล้วกด Start หรือส่งข้อความให้บอตอย่างน้อยหนึ่งครั้ง
3. เปิด URL นี้ในเบราว์เซอร์ โดยแทนที่ TOKEN ด้วย Token ของตัวเอง: `https://api.telegram.org/botTOKEN/getUpdates`
4. หาเลข `chat.id` จากผลลัพธ์
5. ใส่ค่าใน `.env`:
   ```env
   PORT=3000
   TELEGRAM_BOT_TOKEN=ใส่โทเคนของบอต
   TELEGRAM_CHAT_ID=ใส่หมายเลขแชต
   DEFAULT_WATCHLIST=NVDA,TSLA,AVGO,EOSE,JEPQ,VOO
   ```
6. เริ่มเซิร์ฟเวอร์ใหม่ แล้วกดปุ่มทดสอบ Telegram ในเว็บไซต์
7. เมื่อเชื่อมต่อสำเร็จ ระบบจะส่งรายงานอัตโนมัติทุก 5 นาที และแจ้งข่าวสำคัญที่พบใหม่ สามารถกำหนดรอบได้ด้วย `TELEGRAM_INTERVAL_MINUTES` (ขั้นต่ำ 5 นาที) หรือปิดด้วย `TELEGRAM_AUTO_REPORT=false`
8. กดปุ่ม “ส่งรายงานทันที” เพื่อทดสอบส่งรายงานหุ้นทั้งหมดได้

**ห้ามส่ง Bot Token ให้ผู้อื่น และห้ามอัปโหลดไฟล์ `.env` ขึ้น GitHub**

## แหล่งข้อมูลและข้อจำกัด
- ราคาหุ้นและประวัติราคา: Yahoo Finance chart endpoint (ไม่ใช่บริการเรียลไทม์ที่รับประกัน และอาจถูกจำกัดการเรียกใช้)
- ข่าว: Google News RSS (พาดหัวและลิงก์อาจเปลี่ยนแปลงตามภูมิภาค/คำค้น)
- การสรุปข่าวเป็นเพียงการคัดคำจากพาดหัว ไม่ได้อ่านหรือเข้าใจเนื้อหาข่าวเต็ม และอาจจัดหมวดผิดได้ ควรเปิดอ่านต้นฉบับเสมอ
- ตัวชี้วัดและระดับราคาใช้ข้อมูลย้อนหลัง ไม่ใช่การคาดการณ์หรือคำแนะนำซื้อขาย
- รายงานอัตโนมัติทำงานภายในโปรเซส Node.js หาก Render หยุด/พักบริการ รีสตาร์ต หรือมีหลาย instance รอบเวลาอาจคลาดเคลื่อนหรือเกิดการส่งซ้ำได้ หากต้องการความเสถียรระดับ production ควรแยกเป็น Cron Job/Worker
- ราคาก่อนเปิด/หลังปิดตลาดขึ้นกับข้อมูลที่ Yahoo Finance ส่งกลับ หากไม่มีข้อมูล ระบบจะแสดงว่าไม่มีข้อมูล ไม่ได้ประมาณราคาเอง
- ข่าวสำคัญตรวจจากคำสำคัญในพาดหัวและอาจแจ้งผิด/พลาดข่าวได้
- ไม่มีค่าใช้จ่าย AI API แต่ผู้ให้บริการภายนอกอาจเปลี่ยนเงื่อนไขหรือจำกัดการใช้งานได้
